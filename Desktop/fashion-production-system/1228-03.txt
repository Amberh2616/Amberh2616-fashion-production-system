### 3. Serializers with Guard Rules (✅ DONE)

**File:** `backend/apps/costing/serializers.py`

**Key Components:**

**A/B Field Definitions:**
```python
A_FIELDS = {
    "labor_cost", "overhead_cost", "freight_cost",
    "packaging_cost", "testing_cost", "notes",
}
B_FIELDS = {"margin_pct", "wastage_pct"}
```

**CostSheetPatchSerializer:**
```python
def validate(self, attrs):
    """Guard Rule: Block B-field modifications"""
    incoming = set(attrs.keys())

    # Block B fields
    if incoming & B_FIELDS:
        raise serializers.ValidationError({
            "version_policy": "margin_pct and wastage_pct require a new version."
        })

    # Ensure only A fields
    illegal = incoming - A_FIELDS
    if illegal:
        raise serializers.ValidationError({
            "fields": f"Illegal fields: {sorted(list(illegal))}"
        })
```

#### PATCH /api/v2/cost-sheets/{id}/
**Changes:**
- Uses `CostSheetPatchSerializer` (with guard rules)
- Returns **409 Conflict** if B-fields modified
- Uses `calc_totals()` for auto-recalculation
- Updates `updated_by` and `updated_at`

**Response Format (409 Conflict):**
```json
{
  "error": "VERSION_POLICY_VIOLATION",
  "message": "margin_pct and wastage_pct require a new version.",
  "details": { ... }
}
```

#### POST /api/v2/cost-sheets/{id}/duplicate/ (NEW)
**Purpose:** Pure negotiation (same BOM, different pricing stance)

**Logic:**
1. Copy source CostSheet (keep A-fields)
2. Apply new margin_pct and wastage_pct (B-fields)
3. Copy all CostLines (same snapshot)
4. Recalculate line_cost with new wastage
5. Recalculate totals with new margin
6. Auto-increment version_no
7. Set is_current=true (old→false)

**Use Case:**
- Buyer countered: "30% margin is too high, can you do 25%?"
- System: Duplicate v1 → v2 (margin: 30%→25%)
- Preserved: Same BOM snapshot (no material changes)
- Changed: Only pricing strategy

### 2. Version Policy Enforcement
```python

  "margin_pct": 25.00  # ❌ B-field

# Response: 409 Conflict

  "error": "VERSION_POLICY_VIOLATION",

# Correct approach

}
```
