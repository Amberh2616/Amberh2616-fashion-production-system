## Implementation Overview

### A/B Field Classification（欄位分類）

**A Fields（同版本可修改）:**
- labor_cost
- overhead_cost
- freight_cost
- packaging_cost
- testing_cost
- notes

**B Fields（必須新版本）:**
- margin_pct
- wastage_pct

**設計理由:**
- 成本估算變更 → 不需要新報價版本（談判立場不變）
- 定價策略變更 → 必須建立新版本（談判歷史追溯）

### Task 3: Serializers with Guard Rules ✅

**Key Serializers:**

1. **CostSheetPatchSerializer（Guard Rules）:**
```python
def validate(self, attrs):
    """PATCH 禁止修改 margin_pct 或 wastage_pct"""
    incoming = set(attrs.keys())

    # Block B fields
    if incoming & B_FIELDS:
        raise serializers.ValidationError({
            "version_policy": "margin_pct and wastage_pct require a new version."
        })

    # Only allow A fields
    illegal = incoming - A_FIELDS
    if illegal:
        raise serializers.ValidationError({
            "fields": f"Illegal fields: {illegal}"
        })
```

```typescript
export function useDuplicateCostSheet(
  costSheetId: number,
  revisionId: string
) {
  const queryClient = useQueryClient();

  return useMutation({
    mutationFn: (payload: DuplicateCostSheetPayload) =>
      duplicateCostSheet(costSheetId, payload),
    onSuccess: (data) => {
      // Invalidate list to show new version
      queryClient.invalidateQueries({ queryKey: ['cost-sheets', revisionId] });
      // Update detail cache
      queryClient.setQueryData(['cost-sheet', data.id], data);
    },
  });
}
```

      dirty.push(key);
    }
  });
  return dirty;

**2. B-Field Detection（B 欄位判斷）:**
```typescript
const B_FIELDS = new Set(['margin_pct', 'wastage_pct']);

const hasBFieldChanges = useMemo(() => {
  return dirtyFields.some((field) => B_FIELDS.has(field));
}, [dirtyFields]);
```

```typescript
const onSubmit = (data) => {
  if (hasBFieldChanges) {
    // B-fields → Duplicate API
    duplicateCostSheet({
      margin_pct: data.margin_pct,
      wastage_pct: data.wastage_pct,
      notes: data.notes,
    });
  } else {
    // Only A-fields → PATCH API
    const payload = {};
    dirtyFields.forEach((field) => {
      if (A_FIELDS.has(field)) {
        payload[field] = data[field];
      }
    });
    updateCostSheet(payload);
  }
};
```
